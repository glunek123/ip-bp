# 知产案件管理系统 Demo（v152）

这是从原换机包中提取出的终版 Demo 源码，已移除个人资料、工作记忆、历史版本、备份、Git 历史、运行日志和重复交付物。

## 运行

直接用浏览器打开 `index.html`。项目为纯静态页面，无构建步骤、无包管理器依赖、无后端服务。

页面引用关系：

```text
index.html
├── styles.css
└── app.js
```

`index.html` 还会尝试加载 Google Fonts；网络不可用时会回退到系统字体，不影响主要功能。

## 文件结构

- `index.html`：页面结构、静态首屏和各业务视图容器。
- `styles.css`：全部视觉样式与响应式规则。
- `app.js`：演示数据、状态、业务流程、渲染、交互及导出逻辑。
- `DESIGN.md`：原 Demo 的设计系统与界面约束，反向工程 UI 时可作为参考。

## 业务范围

Demo 覆盖线索库、公证流程、案件管理、客户管理、证物管理、日历、费用中心、结算中心、数据报表和系统设置。案件与公证流程由 `app.js` 中的阶段配置驱动。

## 数据与状态

- 初始演示数据直接定义在 `app.js` 中。
- 运行状态保存在浏览器 `localStorage`。
- 主数据键为 `ipcase_demo_v2`，当前数据版本为 `SAVE_VER = 21`。
- 修改种子数据或数据结构后，应同步提升 `SAVE_VER`，否则浏览器可能继续读取旧缓存。
- 若需恢复初始演示数据，可在浏览器开发者工具中清除该站点的本地存储后刷新。

## 反向工程提示

- 这是一个大型单文件原生 JavaScript 原型，没有模块系统和框架。
- HTML 中大量 `onclick` 会调用 `app.js` 的顶层函数。
- `renderAll()` 是主要的全局刷新入口；各业务域另有独立的 `render*` 函数。
- `save()` / `load()` 负责持久化，`defaultState()` 负责构造初始状态。
- `STAGES`、`LEAD_STAGES` 与公证流程配置是理解状态流转的主要入口。
- `data-page-node-id` 是设计工具导出的节点标识；若还需要映射原设计稿，建议保留。

## 接手建议

先保持当前三件套可运行，再按业务域逐步拆分 `app.js`。优先分离数据模型与持久化、流程配置、领域服务、视图渲染和通用 UI 组件；每拆出一层，都用原页面行为进行对照验证。
