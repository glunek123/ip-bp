# 知产业务目标语境

本词汇表用于本版Spec统一表达，不定义表结构或新增业务约束。基于v158字段语义及已有用户决定；尚未决定的关系见DOMAIN和GAPS。

## Language

**客户**：委托维权服务的业务主体，可为企业、个体工商户、自然人、事业单位、社会组织等；不等同于其登录账号或具体权利主体。
_Avoid_: 把案件中的client字段直接称为客户。

**角色模板**：一组可由有权管理员维护的默认操作权限与数据范围，用于快速给人员授权；“主管／小组长／运营”是初始模板名称，不是代码中永久固定的权限。
_Avoid_: 只凭职位名称放行，或为了个别案件临时协作而提升全局职位。

**操作权限**：系统已经提供的一个具体动作，例如建草稿、准入、转派、下载或归档。
_Avoid_: 让后台配置凭空创造新业务动作，或把“可查看”自动扩大为“可编辑／导出”。

**数据范围**：某项操作允许作用的对象集合，例如本人负责、本人参与、本团队、本部门或明确授权部门。
_Avoid_: 把一个授权中的操作权限与另一个授权中的更大数据范围拼接成未授予的权限。

**资源成员**：在单个案件等资源上登记的负责人、律师或协作人员，是角色授权之外的个别访问来源。
_Avoid_: 移除案件成员后假定其一定失去所有访问；其仍可能通过部门角色获得权限。

**有效授权**：一次服务端请求中，能够同时覆盖目标操作与目标对象范围的单个授权来源。
_Avoid_: 仅隐藏前端按钮、相信客户端提交的角色／部门，或先读取全量数据再在内存中过滤。

**客户资料状态**：客户主档是否已经满足正式业务准入条件；“草稿”可继续补资料但不能进入正式取证或案件，“已准入”表示当前必需身份信息和正式证明已通过校验。
_Avoid_: 用合作中／暂停／终止表达资料是否完整，或把草稿客户当成正式业务可选客户。

**合作状态**：客户合作关系处于合作中、暂停或终止；它与客户资料状态分别表达，暂停／终止不删除历史业务。
_Avoid_: 把“已准入”等同于“合作中”，或因合作终止把客户身份和历史关联删除。

**权利主体**：在具体权利或维权事项中被关联的权利人主体；与客户分别识别。
_Avoid_: 不区分委托客户的“主体”。

**线索**：尚待审核和取证决策的涉嫌侵权信息及相关商品、材料。
_Avoid_: 将线索记录直接称为诉讼案件。

**公证事项**：公证模块承载的业务记录；其来源可为线索取证或合并原案归档，后者不表示重新办理取证。
_Avoid_: 把所有公证归档记录都称为新公证申请。

**案件**：承载诉讼、审理、执行和结案信息的业务记录，与来源线索、公证事项分别识别。
_Avoid_: 使用无对象类型的caseId解释所有关联。

**业务单号**：内部业务识别号码，与法院形成的诉调号、法院案号和执行案号分别表达。
_Avoid_: 无上下文的“案号”。

**费用**：具有来源、金额、方向及处理信息的支出或退款等业务记录。
_Avoid_: 把净额展示行当成一笔原始费用。

**结算发起**：提出一次结算处理的业务动作，不表示实际款项已经完成。
_Avoid_: 将已发起金额标为“已结算”。

**结算明细**：按案件及结算侧记录的某次结算金额与收付方信息，是账单组织的对象，与原始费用分别识别。
_Avoid_: 把费用汇总行直接称为结算明细。

**账单**：组织结算明细的汇总单据；各明细保留自己的收付方。
_Avoid_: 把汇总单据的首个收付方代表所有明细。

**归档**：业务记录的归档事实，不代替结案、费用支付或结算完成事实。
_Avoid_: “已结案结算”作为单一状态。

**明确无**：操作者针对要求选择的业务项明确确认“不存在／不适用”，与未填写、未知或识别失败不同。
_Avoid_: 把文本“无”存成真实快递公司、单号或拿去自动匹配。

**可恢复删除**：文件从普通可见集合移除，但仍存在独立恢复路径；不等于物理永久清除，也不等于作废业务事实。
_Avoid_: 将“可删除”实现为立即硬删除；普通未引用文件删除后保留90天，被业务引用的文件只能版本替换并作废旧版。

**历史补录**：通过独立入口登记已发生的历史案件及其真实业务信息，不是普通新建案件任意跳过正常流程。
_Avoid_: 用“不设正常阶段门槛”推导无需记录来源、真实日期、原因或操作者。

**金额待定**：业务已经确认存在金额事项，但当前尚不能给出可靠数值；与金额0及未填写不同。
_Avoid_: 用0代替未知金额，或用负数承担退款／支出的业务方向。

**合并办理组**：把同一客户的多个案件组织为可解除的联合办理关系，各源案及其主体、被告、材料、费用和外部引用仍保持原身份与归属。
_Avoid_: 新建替代主案、删除源案或把聚合展示结果当成新的业务事实。

**受控直接动作**：有权角色直接执行受限业务动作并填写原因、留下审计记录，不产生独立审批单或多级审批流程。
_Avoid_: 把“主管控制”自动扩展成审批中心、审批队列或额外状态机。

**材料、证物、公证书**：材料指业务附件及内容；证物指保管对象；公证书具有出证资料和纸质件状态，三者不相互代替。
_Avoid_: 将文件名等同于已保存的文件原件。

**律师费发票**：律师针对运营发起的律师结算／账单上传的发票材料，与账单、结算发起和实际付款结果分别识别。
_Avoid_: 上传发票即视为财务已支付或结算完成。
