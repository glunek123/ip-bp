# RP 报表

报表无独立业务办理状态；每项指标必须有来源、范围和口径，界面图表存在不等于所有图表均获准纳入正式范围。

依据：[固定事实](../../../demo-reverse/v158/modules/M08-reports.md)、[候选](../../../demo-reverse/v158/modules/M08-reports-candidates.md)、[决定](../../../demo-reverse/v158/DECISIONS.md)和[纠偏](../../../demo-reverse/v158/CORRECTIONS.md)。字段见[领域模型](../DOMAIN.md)，B/T/E见[缺口](../GAPS.md)，通用技术设计见[TD-BASE-05／TD-TRACE-UX-01](../TECHNICAL-DESIGN.md)。本模块TD-SLICE、API、实现、迁移及正式测试未产生；所有AC为未执行目标场景。

## REQ-RP-001 已归档案件平均标的额

- 状态：确认方向（BD-11）。来源：R-C01 BD-11 FIX-26。字段组：RP01/CA01/CA04/CA10。
- 目标／动作与结果：指标名称为已归档案件平均标的额，使用已归档案件标的额平均，不改用结案额。金额运算为数值，不拼接字符串；数据范围内无记录的展示需明确。
- 异常、边界及待决：第一版人民币已确认；时间范围、缺金额、空集及均值显示舍入仍待B17/22；不引入跨币种平均。
- 依赖：B17/B22/T04/T06；所有操作者和数据范围受REQ-XM-001约束，失败／批量／重复处理结合REQ-SH-004。
- AC-RP-001：**给定／操作**：同一获准统计范围和币种内两个已归档案件，标的1000/3000、结案100/200。**预期**：未涉及舍入时均额2000，名称正确，不取150；精度／空集显示待口径确认。

## REQ-RP-002 页面导出和权限范围

- 状态：部分确认（SD-13）＋纠偏约束；指标待审核。来源：R-C02 R-C03 FIX-26。字段组：RP01/CU08。
- 目标／动作与结果：客户可查看仅包含本企业案件数据的报表；页面与导出同名指标采用同一字段及计算口径。发布／归档报表记录生成时间、筛选期间、指标定义版本、导出人及精确文件版本，与当前实时重算分开。类型／平台、标的桶、法院TOP5、案件数与结案率仍是待审核指标。
- 异常、边界及待决：各指标具体边界、无值、时间范围和是否导出B22；导出任务执行和领取时分别按当前权限确定可见数据，统计总数和缓存不泄漏跨部门数据；不恢复无挂载看板，不建设数据仓库或历史重算平台。
- 依赖：B03/B17/B22/T03/T04/T06；所有操作者和数据范围受REQ-XM-001约束，失败／批量／重复处理结合REQ-SH-004。
- AC-RP-002：**给定／操作**：获准范围两案金额为可合法解析的100和200；生成并发布同指标报表，之后数据变化并撤销导出权限，再尝试领取。**预期**：发布文件保留当时口径版本和精确内容，不随实时值改变；撤权后领取被拒绝且不泄漏跨部门数量；边界口径仍依B22。
