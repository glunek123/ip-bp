# SY 模板与数据管理

设置页中的Demo本机重置不是正式管理功能授权。迁移、恢复和模板只保留有依据的目标约束，功能范围逐项审核。

依据：[固定事实](../../../demo-reverse/v158/modules/M09-settings.md)、[候选](../../../demo-reverse/v158/modules/M09-settings-candidates.md)、[决定](../../../demo-reverse/v158/DECISIONS.md)和[纠偏](../../../demo-reverse/v158/CORRECTIONS.md)。字段见[领域模型](../DOMAIN.md)，B/T/E见[缺口](../GAPS.md)，通用技术设计见[TD-BASE-05／TD-AUTHZ-01／TD-TRACE-UX-01](../TECHNICAL-DESIGN.md)。本模块TD-SLICE、API、实现、迁移及正式测试未产生；所有AC为未执行目标场景。

## REQ-SY-001 迁移及恢复边界

- 状态：纠偏约束；功能范围待定。来源：D-C01 FIX-21 FIX-22 FIX-23。字段组：SY02。
- 目标／动作与结果：若批准迁移／导入功能，包须声明版本和范围，完整覆盖声明的数据与关联；账单、模板不能静默遗漏。先验证候选数据再应用，失败保持原状态；合法空集合不补种子。
- 异常、边界及待决：Demo重置不进入正式系统；迁移、备份恢复、加密和升级兼容由T07／运维设计，不作为普通业务页面。正式导出材料范围见BQ-11。
- 依赖：BQ-11/T02/T07；所有操作者和数据范围受REQ-XM-001约束，失败／批量／重复处理结合REQ-SH-004。
- AC-SY-001：**给定／操作**：原系统有客户、案件、账单和模板；导入缺必要客户集合的包；另导出声明包含全部集合的包。**预期**：无效包不能先清案件再报错；导出范围包含声明集合，隔离恢复逐集合核对；范围未批准前为条件性验收。

## REQ-SY-002 模板真实性与适用范围

- 状态：纠偏约束＋待审核。来源：D-C02 FIX-24。字段组：SY01/MT01/CA04。
- 目标／动作与结果：上传模板必须区分文件名、格式和真实内容；不可读时明确失败或待处理，不用内置模板冒充上传文件。明确选择内置模板才使用内置内容，适用案由与法律措辞需业务审核。
- 异常、边界及待决：正式文件格式、模板版本和校核按模板模块开发批次确定；SD-09确认OCR候选须人工审核；不把HTML改后缀称为结构化DOCX。
- 依赖：BQ-11/SD-09/T05/T07；所有操作者和数据范围受REQ-XM-001约束，失败／批量／重复处理结合REQ-SH-004。
- AC-SY-002：**给定／操作**：上传文件名甲但内容不可读的模板后预览；再显式选择内置模板乙。**预期**：甲不显示乙内容并声称上传成功；显式选择乙时名称和来源明确，不能把演示法律结论写成真实案件事实。

## REQ-SY-003 导出、下载与运行说明

- 状态：纠偏约束＋范围待定。来源：D-C03 D-C04 FIX-27。字段组：MT01/SY01/SY02。
- 目标／动作与结果：说明与实际资产一致，导出注明真实格式、来源及包含范围，下载成功必须对应实际产物，不以toast代替。原件与生成文书区分，不能在原扩展名下伪造内容。
- 异常、边界及待决：导出权限／审计／正式格式B03/21/23；换机三件套纠偏仅属Demo说明参考，不要求正式系统使用静态三件套部署。
- 依赖：BQ-03/BQ-11/T05/T07；所有操作者和数据范围受REQ-XM-001约束，失败／批量／重复处理结合REQ-SH-004。
- AC-SY-003：**给定／操作**：下载一份业务原件和一份由模板生成的文书，查看运行／迁移说明。**预期**：两者来源及格式可区分，原件内容未被模拟替代；说明不再声称当前Demo为旧单HTML自包含；正式部署说明等实际设计后产生。

## REQ-SY-004 人员与权限管理

- 状态：确认方向（SD-28/29/31/33）；TD-AUTHZ-01已设计，Q2安全复核及实现未产生。字段组：AC01～06。
- 目标／动作与结果：在“系统设置→人员与权限”维护人员组织归属、角色模板、操作权限、数据范围和角色分配；模板支持复制和修改，保存前显示受影响人员。公司权限管理员默认管理模板及跨部门授予，主管／小组长默认管理各自范围，但这些管理权本身也由可授予范围控制。
- 异常、边界及待决：不开放自助注册、共享账号、自我提权或越级授予；高风险变更要求原因并审计，但不增加多级审批。后台只列出系统已实现的权限代码，不提供自定义表达式或新业务动作。实际SSO／OIDC、内部账号安全、MFA和会话策略仍依E01。
- 依赖：REQ-XM-005、T03/E01；所有保存从下一次服务端请求生效，不能只修改前端菜单。
- AC-SY-004：**给定／操作**：复制运营模板并新增下载权限但范围仍为本人，分配给用户甲；用户甲尝试给自己增加本部门编辑并访问部门乙。**预期**：复制和合法分配成功；自我提权、超授予范围和跨部门访问被拒绝且留审计，模板变更影响范围可预览。
