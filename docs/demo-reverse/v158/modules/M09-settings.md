# M09 设置、模板与数据迁移：源码事实

A=[app.js](../../../../demo/app.js)。本轮复核L1176–1193、L2951–3007、L7620–7643、L9638–9664、L12136–12307；固定版本见 [INVENTORY](../INVENTORY.md)，公共存取见 [M00](M00-shared.md)。只记录本地 Demo，不等于正式备份恢复设计。

## 入口及实体

设置视图提供JSON导入／导出、重置、复制换机说明、模板上传／预览／删除。客户CSV及本月结算CSV为其他页面下载入口，见M10/M06，处理辅助函数L7621–7638。模板消费还包括案件批量诉状导出。

| 对象／字段      | 实际类型／约束                                                                                                          | 位置                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| JSON包          | __app字符串、__version=2、__exportedAt UTC；state、leads、notary、evidences、notaryDocs、calEvents、custBills、lawBills | L12136–12149             |
| DOC_TEMPLATES[] | id/type/name/size/date/content；内置T-001；上传ID=毫秒；type固定起诉状，content文本，size展示字符串                     | L9659–9662、L12258–12280 |
| 设置统计        | 案件／客户／线索／公证／证物／公证书／事件数量；localStorage主键内容的Blob大小，非全站存储                              | L12212–12228             |

## 动作、校验、输出、异常

1. 导出只序列化上表集合，生成本地JSON下载后提示成功；**不包含独立BILLS和docTemplates**，与save保存范围不一致。无服务器备份（L12136–12157；M00存储字段）。
2. importData读取UTF-8 JSON，仅检查data.state.cases为数组，然后applyImport。后者先替换全局STATE，再遍历补旧字段、被告／日志／律师结算种子、付款类型及收款人；随后直接遍历customers。缺customers可在替换STATE后抛错，外层提示失败但不恢复原内存状态。未验证版本、关联完整性或整包原子替换（L12160–12197）。
3. restoreExtras后save，再autoFlowCases/renderAll/renderSettings。因此导入不是完全保留文件原状；可能补演示值及触发到期流程。外层读取失败清文件输入，解析／处理异常toast，无回滚（同上）。
4. resetDemo确认后移除SK，恢复defaultState与DEMO_DEFAULTS、补各阶段演示案件、save/render；存储访问异常吞掉，内存照常重置。并非正式数据删除授权（L1176–1191）。
5. 模板上传readAsText；空内容或替代字符超过2%则**改用内置模板内容，却保留上传文件名**，并提示按内置结构登记；不是DOCX解析。新模板放首项、保存及重绘。预览HTML转义；删除查首个ID直接移除，无另一次确认，内置也可删（L12231–12297）。
6. 批量诉状优先勾选中待写诉状案，无勾选取全部待写诉状；选择首个起诉状模板，没有则引导上传／内置。按client分目录，以被告命名.doc，重名加案件ID；文件实为HTML文书，打ZIP。异常提示失败。内置文字固定商标侵权请求及“证据充分”等演示措辞，不能当作任意案由可直接采用的业务事实（L2951–3003、L9638–9657；填充规则见M02/M00）。
7. copyFileHint仍说自包含ip-case-system.html，与当前index.html/app.js/styles.css实际包不符（L12200–12209）。本月账单只取CUST_BILLS/LAW_BILLS当前月，不包含BILLS汇总对象；空列表只提示不下载（L7629–7638）。
