# M10 客户：正式系统输入候选

可确定纠偏见 [CORRECTIONS](../CORRECTIONS.md)：移除新建虚构数据、稳定身份不依数组长度、改名不破坏关联、识别失败保留未知。以下仍需业务／产品／财务决定：合作暂停／终止是否阻止新业务；客户／主体删除和留存；多联系人主要标记约束；资产有效期缺失或无固定期限的展示；结算统计分母及账单去重。未决不妨碍其他模块源码提取，不擅自用行业常识补齐。

正式流程输入：客户建档→主体／联系人／权属资料维护→线索及案件选取关联→合作条件供结算使用；协议和资料更新、合作状态变更是独立维护动作。Demo 没有在这些动作之间实现审批状态机，是否需要审批UNKNOWN。

需求—页面／函数—字段—场景映射通过本表回到M10事实。正式需求批准版本（除BD具体项）、设计、API、业务代码、数据库迁移及业务测试尚未产生。
