# M10 客户：源码事实

固定版本及全读记录见 [INVENTORY](../INVENTORY.md)／[COVERAGE](../COVERAGE.md)。A= [app.js](../../../../demo/app.js)，H= [index.html](../../../../demo/index.html)。本模块复核 A:L318–386、L1034–1090、L5266–5420、L5887–6112、L6994–7393，并追踪本文列出的共享函数。事实与[候选输入](M10-customers-candidates.md)、[用户决定](../DECISIONS.md)、[修正口径](../CORRECTIONS.md)分离。

## 入口及归属

前端 `customers` 列表→`openCustomer(id)`→`customer-detail`，基本信息／权利资产／结算记录三个页签，非 HTTP 路由（H:L1873–1940、L2075–2170、L2256–2268、L2341–2357；A:L5266–5272）。动态入口包括新建／编辑／删除客户、联系人、权利主体、权利资产、协议上传预览、单行重传、批量识别预览提交及对账单导出；A:L5333–5390、L6994–7393。列表按状态、名称／信用代码／主营类目检索，**不搜索联系人**，与占位文案不符；A:L1674–1680、H:L1919。经理选择器和装饰勾选框不能当作已实现业务筛选或批量客户动作（H:L1921–1923、A:L1688–1689）。

## 处理、状态、副作用与异常

1. 新建名称必填，公式只需可提取0–100百分比。生成ID、插入首行、状态合作中，再混入 `customerExtras()` 的三联系人、五资产、协议文本、开票银行及固定合作日期；只有holders改为客户自身（A:L1060–1088、L6994–7029）。失败公式返回false不关闭。无重名／重复代码阻止。
2. 编辑覆盖档案字段，再调用经理／运营统一写入口；没有改名级联，按旧名字关联的账单／案件不跟随（A:L7035–7087）。经理或运营改变时各自save/render，最后再次save/render，不是事务。协议只有本次选择才覆盖；取消不提交（异步文件读取竞态未实际核验）。
3. 删除客户确认后只过滤STATE.customers，嵌套联系人／主体／资产随对象移出；未在此路径处理案件、线索、账单中的客户名称（A:L7092–7102）。关联留存不是已确认策略。
4. 联系人直接push/Object.assign/splice；删除无确认；主要联系人可多个。主体增改必填四项，删除有确认；改名不重写历史案件／线索，删光可保留空数组（A:L7105–7148、L7340–7393）。恢复仅非数组才selfHolder（A:L1161）。
5. 资产手动登记允许空编号、空名称、空文件；默认权利人客户名、日期今日及10年后。修改重传触发识别覆盖候选表单；单行“重传”则直接覆盖已保存资产，不设第二次确认（A:L690–698、L7151–7244）。删除按下标，无确认。
6. 识别是正则＋文件名分类，不是外部AI。文件名分类优先；正文匹配号码、名称、类别、权利人和日期；缺失字段由哈希示例、当前客户、今日／10年后补齐，失败读取也走此路径（A:L6020–6075）。未识别≠真实默认值。
7. 批量打开清草稿，文件并行读文本，全部回调完成后排序预览；无文件提示，空草稿不可提交；提交全部push，清草稿、save并关闭。未发现去重、逐行校验、取消异步回调失效令牌或跨客户归属锁定；提交重新取curCustomer（A:L7247–7315）。这些竞态尚未实测，不表述为已发生。
8. 协议上传读文本→覆盖单份协议→本地save→预览转义正文；无文件取消，无法读文本保存失败说明，不能声称文件存储成功（A:L5333–5390）。

## 跨模块及统计边界

- 客户→权利主体是一对多**数组实现**（H:L1877）。M01的client是客户、party是主体；M02的cust是客户、client是主体，不可因同名键合并概念。
- 结算记录按客户名过滤SETTLEMENTS，再按客户＋月份将CUST_BILLS中缺失月份加入并倒序；同月已有记录会遮蔽新账单；账单正文独立在CUST_BILLS按月取首个（A:L5277–5289）。导出同一合并列表，可选月份，无记录不下载（A:L5320–5329）。M06继续追踪创建与回执。
- 详情KPI仅汇总SETTLEMENTS而非custSettlements，累计回款为received非零否则回退c.recovered；回款率直接c.rate，待回款max(0,inv-rec)。列表在办数直接c.cases，不能认为与实时案件自动一致（A:L1683–1703、L5934–5972）。CTA按合并账单求待回款总额，却固定写月结30天（A:L5856–5876）。
- 公式解析只找百分比，不执行等式，`结案金额*-70%`和任意含70%的字串都可解析为70；旧share缺失时 `Number(null)=0` 可能得到0而非注释中的70（A:L5421–5436）。M06负责金额计算；此处不制定财务规则。
- 渲染子模块try/catch打印console.error后继续，不等于数据正确；文件回调失败降级而非明确失败中止（A:L5883–5928、L7240、L7285–7287）。
