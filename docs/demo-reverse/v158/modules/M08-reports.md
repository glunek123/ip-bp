# M08 报表：源码事实

A=[app.js](../../../../demo/app.js)。完整复核 L7578–7600、L9201–9313；版本见 [INVENTORY](../INVENTORY.md)。本模块无独立持久实体，读取案件、客户、公证事项后计算展示／下载CSV。

## 入口和指标

数据报表前端视图→renderReports；导出→exportReportsCSV。历史renderDashboard在缺少view-dashboard时直接返回，不将保留函数视为当前工作台页面。report-ops也有空节点守卫（L9219–9221、L9265–9271）。

| 指标／输出       | 当前计算口径                                                               | 位置                     |
| ---------------- | -------------------------------------------------------------------------- | ------------------------ |
| 案件总数／进行中 | STATE.cases.length／status不为已归档；无部门、时间筛选                     | L9245–9259               |
| 累计标的额       | 各案件numOf(amount)相加，wan按万元保留1位                                  | L9201–9202、L9249、L9257 |
| “平均结案金额”   | 已归档案件的amount平均，**不是closeAmt**；分母至少1                        | L9250–9258               |
| “结案率”         | 已归档数量／全部案件，分母至少1，百分比Math.round                          | L9259                    |
| 类型／平台       | type原值分组；platformOf优先platform，兼容旧被告字符串；空平台归—          | L9261–9263、L9283–9293   |
| 标的额分布       | [0,10万)、[10万,30万)、[30万,50万)、[50万,∞)，使用numOf                    | L9273–9281               |
| 法院TOP5         | normBlank排除占位，court字符串分组按数量倒排取5                            | L9295–9305               |
| CSV              | 阶段、类型数量；案件数、客户数、累计标的额、公证非归档数；并非屏幕全部图表 | L7578–7592               |

barChart宽度按当前最大值归一化，不是总量占比。空图返回暂无数据。金额工具numOf会丢负号等限制见 [M00](M00-shared.md)及 [FIX-02](../CORRECTIONS.md)。显示格式和金额业务精度不能混为一谈。

## 异常和副作用

导出金额直接`a + (c.amount || 0)`，而页面用numOf；遇字符串金额可发生拼接，下载成功提示不验证指标正确。下载无费用或业务状态修改（L7589–7592）。未发现本段时间／角色范围参数；这不能替代正式系统后端授权。历史看板“本月应收”实现没有月过滤，quick-settle有月过滤，但当前看板不可见，不能宣称用户可操作该入口（L9231、L9241）。

## 场景（源码推导）

| 编号 | 前置／操作                                  | 可观察结果                                       |
| ---- | ------------------------------------------- | ------------------------------------------------ |
| RS01 | 已归档案amount=1000、closeAmt=100，刷新报表 | 平均采用1000而不是100；L9251–9253                |
| RS02 | 金额=100000，刷新分桶                       | 进入10–30万，不进入10万以下；L9273–9281          |
| RS03 | 两案amount字符串“100”“200”，导出            | reduce结果为字符串“0100200”，不是300；L7589      |
| RS04 | 空案件集合，刷新                            | 总数0、平均0、结案率0，不因分母0报错；L9253–9259 |

这些不是正式统计需求。指标更名、结案口径、时间维度、金额精度、币种及权限范围见 [候选输入](M08-reports-candidates.md)。
