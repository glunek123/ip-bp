| 编号  | 模型／规则输入                                                             | 待确认／映射                                                                                                    |
| ----- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| K-C01 | 业务事件：稳定ID、来源类型／来源ID、日期或时间、标题、关联案件或客户、状态 | 自动派生与手工记录分开；来源更正、取消同步，不能靠文本猜案；DD-01/02/05/06，CS01/02/04                          |
