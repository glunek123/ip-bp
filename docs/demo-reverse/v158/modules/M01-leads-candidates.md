## 候选规则与业务流程

观察到的主流程：录入／导入 → 待推送 → 侵权审核 →（不侵权归档／侵权后取证确认）→（不取证归档／转公证）。这是审核草案；“客户／运营”审核角色尚非权限分配。

| 决策             | 需要确认的问题（对应事实差异）                                                                       | 决策角色建议／DD／验证映射                         |
| ---------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| L-D01 身份与关联 | 客户、主体、店铺用什么稳定身份；业务单号是否贯穿线索、公证、案件，何时生成；删除是否允许重用         | 业务负责人及主数据负责人；DD-01/02；L-C01/05、LT04 |
| L-D02 一致校验   | 手工／编辑／CSV 是否同一套必填与取值规则；最少商品要求、URL 有效性、未知客户和主体如何处理           | 线索运营／产品；DD-01/04；LT01/02/05               |
| L-D03 推送范围   | 无勾选时是否允许推送全部待推送，还是当前筛选结果／必须勾选；重复推送如何处理                         | 运营／审核负责人；DD-02/04；LT03                   |
| L-D04 审核归档   | 谁判定侵权、谁决定取证；归档类型及原因何时必填；批量能否跨阶段；归档后允许哪些编辑和重新进入动作     | 业务审核负责人；DD-02/03；LT07、LS09/10/12         |
| L-D05 移交留存   | 转公证成功的定义；保留源线索及商品／材料／审核记录的范围；重复确认、失败恢复怎样表现                 | 运营／公证业务负责人；DD-01/02/06/10；LT04         |
| L-D06 估算口径   | 用评论数代替销量是否为业务规则；负数、零、缺失、币种、小数及舍入如何处理                             | 业务及财务负责人；DD-05；LT02/08                   |
| L-D07 导入语义   | 模板版本、逐行失败还是整批失败、重复判断、导入顺序；取消后缓存不应作为待批准规则，需明确预览确认对象 | 运营／产品；DD-02/04；LT05/06                      |
| L-D08 时间语义   | 发现、推送、审核、确认、归档的日期和时区，补录日期是否允许；流水号依创建日还是发现日                 | 业务负责人；DD-01/05；M01 §3/5                     |
