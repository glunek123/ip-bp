# M07 日历：源码事实

A=[app.js](../../../../demo/app.js)，固定版本见 [INVENTORY](../INVENTORY.md)。完整复核 A:L2744–2782、L9490–9514、L11367–11578。下述场景均为源码推导；清空开庭日期的实际观察沿用同一固定版本的 M02 CT05，不冒充本模块新增实测。

## 入口与字段

前端日历导航、上／下月、今天、事件悬浮与点击；不是 HTTP 路由。CAL 初始为 `{y:2026,m:8}`，月份从0开始，今天按钮才取浏览器当前年月。事件由种子及案件开庭同步生成，未在本模块发现独立新增／编辑事件表单（L9510、L11367–11376、L11504–11573）。

| 对象／字段                              | 源码约束与含义                                                                                           | 位置                                   |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| CAL_EVENTS[] date,type,title,sub        | 日期字符串；类型映射court/pay/contract/other；演示事件16条，法律期限和自动续约文字只是种子，非经确认规则 | L9490–9509                             |
| caseId,custId                           | 可缺；点击只解析案件，不按custId进入客户                                                                 | L9491–9506、L11429–11442、L11569–11573 |
| party,defendant,reason,time,place,judge | 开庭提示读取事件自身快照；自动同步只带date/time/place/judge，没有前三字段                                | L2744–2777、L11385–11402               |
| autoCourt,autoSecondCourt               | 按案件ID和标记替换对应自动事件，不删除其他事件；没有统一事件ID                                           | L2748–2774                             |
| CAL、TIP_STORE、tipSeq                  | 当前年月、临时提示Map及序号；renderCalendar清空提示Map；非业务实体                                       | L9510、L11383–11384、L11505            |

## 规则、调用及边界

1. 修改一审／二审开庭日→取前10字符→有值才移除原自动事件并重建→更新案件updated→日历及徽标重绘。一审同时写autoToJudgeAt为次日，二审没有该写入；同步函数本身不save，由外层案件操作保存。空值提前返回，旧事件和一审推进日期残留（L2744–2777；案件调用与自动推进见 [M02](M02-cases.md)）。
2. calMove通常按按钮±1调整；实现超11仅设0并年+1，低于0仅设11并年-1，不是任意跨度月份规范化（L11367–11371）。
3. 案件关联先caseId精确查找，失败再从sub正则抓法院案号并按案件no找首项，可能因重复／失效案号关联不准。能找到案件的非开庭事件提示读取当前客户、权利主体、被告、案号、标的额；开庭提示不回查最新案件（L11407–11442）。
4. 日历按事件date分组，周日为首列，月外格仅填日期；点击能找案件就openCase，否则toast。合同custId不参与路由（L11514–11537、L11569–11573）。
5. “30天内待办”统计当前日期至30日内（含两端）所有类型；其余分类KPI是整个CAL_EVENTS而非当前月。切月不改变这些KPI统计范围。已删除的cal-due容器有空值守卫，不能算当前可见入口（L11539–11567）。
6. 悬浮框有鼠标进出、点击、滚动、窗口尺寸清理及边缘定位；案件被告和律师结算提示即时算，不依赖日历Map持久保存（L11445–11502）。

未发现本模块真实通知发送、服务端定时器、法定期限计算或合同续签执行；范围仅上述源码，不能断言外部系统不存在这些能力。

| 编号 | 前置／操作                           | 可观察结果                                                                             |

| CS01 | 同案已有自动和手工事件，将一审日D改E | 仅该案autoCourt事件替换为E，手工事件保留，autoToJudgeAt=E次日；L2744–2759              |
| CS02 | 一审日D清空再调用同步                | 旧事件和派生日期仍在；L2745–2746；同版CT05已实测                                       |
| CS03 | 自动同步事件，悬浮提示               | 日期／地点／法官有值时显示，权利主体／被告／侵权类型为空占位；L2751–2754、L11385–11402 |
| CS04 | 合同到期事件只有custId，点击         | 仅toast，不进入客户；L11569–11573                                                      |
