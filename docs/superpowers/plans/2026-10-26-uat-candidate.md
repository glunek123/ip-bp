# 本地优化版本交付到测试环境

用户要求交付可部署版本，测试环境另一个任务负责直接准备各阶段及结算中心仿真数据。本轮不生成或导入仿真数据、不操作云端、不推送远端。

交付包含本地已有的中文业务显示、侧栏排版、“知产案管系统”更名、完整客户建档与合作协议，以及新增角色配置快捷全选。现有权限模型已允许同一INTERNAL运营账号拥有CUSTOMER_ADMIT和其他内部权限，不增加准入主管账号，也不按账号名绕鉴权。新增全选只更改角色草稿，沿用角色保存、分配、授权上限、部门隔离及各动作允许的范围。

1. 权限审计确认既有能力；普通UI执行者仅修改RoleTemplateEditor与直接测试，按后端目录选择全部内部动作及各自允许的最高范围，搜索不影响完整选择。
2. 独立审查累积客户后端／迁移与前端组合；不更改bootstrap或共享鉴权。保留全部前序差异及原有`.pnpm-store`。
3. 用完整Git tree导出不含缓存、凭据或本地材料的独立候选；核对全部差异后仅在该候选记录上下文快照，执行完整工程检查及直接相关数据库／页面验证，构建同一源码对应的前后端产物。
4. 交付源码、前后端构建、迁移、版本／文件hash清单及部署交接说明。云端仍由另一个任务按实际环境执行迁移、配置账号并准备仿真数据；未执行的服务器验收不写通过。
