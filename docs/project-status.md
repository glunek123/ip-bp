## 已实现

- 系统统一名称为“品维·知产业务管理系统”，同一系统服务品维部与知产部，服务端承担部门数据隔离与授权。
- 本地账号登录／会话、客户草稿建档／维护、一位准入联系人和权利主体最小关联已形成明确范围内的内部闭环。
- Team作为部门直属主数据约束成员、角色分配和客户的部门一致性；管理Action与Grant Boundary不以首位管理员、角色名称、固定ID或前端菜单绕过。
- “系统设置→人员与权限”已支持原子创建内部账号／凭据／当前部门成员／初始角色，账号和成员启停、管理员重置密码、直接调队、角色撤销／恢复以及最小Team维护。日常操作不要求填写原因或重复输入管理员密码，成功与拒绝仍由后端自动审计。
- 工程已有锁定运行时、上下文与Spec检查、类型／Lint／格式／单元／契约／构建门禁，以及使用独立测试库的Playwright入口。
