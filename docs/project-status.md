## 未决与限制

具体事项仅在 [后续设计清单](deferred-design.md)维护，此处按输入分组。

- **仍按切片确认的业务项**：线下调查／直诉／混包、费用类别与收付方、二审／重审／执行结束、结案资金、证物／公证书实物、结算公式与完整状态、报表口径；只阻断各自范围。详见[业务回件](spec/v0.1/BUSINESS-REVIEW.md)、[缺口](spec/v0.1/GAPS.md)和[就绪清单](spec/v0.1/READINESS.md)。
- **E01真实身份单独阻断**：需要实际身份提供方及OIDC／SSO协议参数、issuer/client/audience与claim映射、秘密交付路径、会话／退出／撤销规则、MFA与账号生命周期、测试租户和测试账号。只阻断真实登录与身份联调；当前合成身份仅用于`NODE_ENV=test`，不阻断本批内部客户规则验证。
- **E02对象存储单独阻断**：需要私有对象存储provider/endpoint/region/bucket、凭据交付路径、加密与密钥归属、签名链接策略、安全扫描边界、保留策略及备份恢复证据和测试bucket。只阻断证件材料、版本和正式准入；本批未写对象存储代码。
- **其他外部条件**：AI供应商、业财协议，以及OPS-01生产环境和CI-01托管平台。原则已定不等于可实施条件齐备。
- **CMP-01 已关闭，保留维护要求**：升级 Element Plus 时必须复验或移除版本绑定补丁，不能手改 node_modules 或放宽类型。见 [组件兼容报告](component-compatibility.md)。
- 工程仍仅适用本地；ESLint 9 和部分间接依赖的弃用提示保留，版本升级单独评估。
