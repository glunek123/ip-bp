# 列表流程按钮名称对照

以下“原名称”指本轮修改前列表上的可见文字；“实际动作”说明仍调用的原办理入口。是否显示仍由阶段、业务事实和权限决定。带未完成原请求的事项使用“核对请求”，不重新发起流程。

| 模块／阶段               | 原名称   | 新名称   | 实际动作                   |
| ------------------------ | -------- | -------- | -------------------------- |
| 线索／待推送             | 推送审核 | 推送     | 推送给客户审核             |
| 线索／待审核             | 代办审核 | 审核     | 运营代办客户审核           |
| 线索／待确认             | 确认取证 | 确认     | 确认取证安排               |
| 线索／可申请撤回归档     | 申请撤回 | 申请撤回 | 申请撤回归档               |
| 公证／待取证             | 登记取证 | 登记取证 | 登记取证日期和物流         |
| 公证／待开箱             | 登记开箱 | 登记开箱 | 登记开箱材料               |
| 公证／开箱待审核         | 审核开箱 | 审核     | 审核开箱                   |
| 公证／开箱待确认         | 出证决定 | 出证决定 | 决定是否出证               |
| 公证／待出证且可代办     | 代办出证 | 代办出证 | 代办公证处出证             |
| 公证／待退货             | 退货归档 | 退货归档 | 办理退货归档               |
| 案件／待匹配             | 匹配案件 | 匹配案件 | 匹配当事人与承办律师       |
| 案件／待写诉状           | 提交起诉 | 提交诉状 | 提交起诉材料               |
| 案件／诉状待确认         | 确认诉状 | 确认诉状 | 确认诉状                   |
| 案件／诉状待盖章         | 邮寄诉状 | 邮寄诉状 | 登记诉状邮寄               |
| 案件／待提交立案         | 提交立案 | 提交立案 | 提交立案                   |
| 案件／待正式立案         | 正式立案 | 正式立案 | 登记正式立案或受理材料     |
| 案件／待开庭             | 登记开庭 | 登记开庭 | 登记开庭                   |
| 案件／待判决             | 登记判决 | 登记判决 | 登记判决                   |
| 案件／判决后待选择       | 选择后续 | 选择后续 | 在现有表单选择判决后续流程 |
| 案件／二审               | 二审办理 | 二审办理 | 二审登记或结果             |
| 案件／适用的执行材料阶段 | 上传材料 | 上传材料 | 上传执行材料               |
| 案件／待写执行材料       | 提交材料 | 提交材料 | 提交执行材料               |
| 案件／执行材料待确认     | 确认材料 | 确认材料 | 确认执行材料               |
| 案件／执行材料待盖章     | 执行邮寄 | 执行邮寄 | 登记执行邮寄               |
| 案件／待申请执行         | 执行立案 | 执行立案 | 登记执行立案               |
| 案件／强制执行中         | 执行结束 | 执行结束 | 登记执行结束               |
| 案件／待归档且可结案     | 登记结案 | 登记结案 | 登记结案资料               |
| 案件／待归档且可归档     | 归档案件 | 归档     | 办理归档                   |

有多个合法后续选择时，仍在原办理表单中选择；短名称不改变操作人、审计或业务结果。
