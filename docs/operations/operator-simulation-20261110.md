## 发现的问题

**P1（体验）：没有变更时点"保存结算更新"，既不发送请求也不给提示。**
运营会以为按钮坏了或保存失败，实际是"无变更可存"。建议：无变更时禁用按钮并显示
"当前没有需要保存的变更"，或在点击后给出明确提示。

**P2（脚本限制，非产品）**：想通过界面改"结案金额"触发一次真实保存时，该字段在当前
数据下不可见（金额已确认时该区块不渲染），因此无法用界面完成"连续两次保存"的复现；
这条路径本轮由 API 验证（201），界面侧仍需人工点一次确认。

## 结论

界面主流程可用，四类角色首屏正常；结算保存的"无变更静默"是唯一的界面反馈缺陷。
归档入口缺失属预期（资金四项未齐）。
