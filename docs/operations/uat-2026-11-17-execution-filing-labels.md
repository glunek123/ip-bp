## 连带修复：无凭证邮寄的 500

为验证执行立案入口，需要把案件推进到「待申请执行」，过程中发现上一轮的「邮寄凭证改备注」在真实提交时会 500。根因是数据库层的延迟约束触发器：

| 层                                     | 限制                            | 处理                                |
| -------------------------------------- | ------------------------------- | ----------------------------------- |
| `check_case_execution_mailing_final`   | 凭证数组长度 1–10               | 迁移放宽为 0–10（`20261117170000`） |
| `check_case_execution_mailing_receipt` | 凭证版本数 1–10                 | 迁移放宽为 0–10（`20261117180000`） |
| 前端 `mailCaseExecution`               | 必填凭证、键集固定              | 允许 0–10、允许 `remark`            |
| 工作流请求 schema                      | 凭证必填                        | 改为选填                            |
| 详情解析 `executionMailing`            | 要求 1 个以上文件、键集精确匹配 | 允许 0 个、只校验必要字段           |

修复后实测：`POST /cases/{id}/execution-mail` 返回 201，`stage` 推进到 `WAITING_EXECUTION_FILING`，备注落库。
