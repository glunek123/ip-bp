## 未完成：诉讼退费（可多笔）

诉求是把一审的「实缴诉讼费 + 诉讼退费（可多笔）」整套带到二审并可改可加。当前系统受限：

| 限制                   | 说明                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| 二审结果接口无退费字段 | `RegisterSecondInstanceResultDto` 只有 `paidLitigationFee`（状态+金额），没有 `refunds`       |
| 案件详情不返回退费明细 | 判决退费只写入诉讼退费库存，详情接口未回传，无法用于预填                                      |
| 写入需接库存链         | 一审退费走 `LitigationRefundsService.registerJudgmentRefunds`，`sourceType` 写死为 `JUDGMENT` |

因此「实缴金额」已按诉求落地，「多笔退费」需要后端扩展后才能可靠保存与回显。

建议方案（待确认）：

1. `RegisterSecondInstanceResultDto` 增加 `refunds`（复用 `CaseJudgmentRefundDto`，最多 20 笔）
2. `LitigationRefundsService` 增加 `registerSecondInstanceRefunds`，`sourceType = SECOND_INSTANCE_RESULT`
3. 案件详情返回二审结果的退费行，供再次编辑时回显
4. 前端表格复用一审样式（退费方 / 金额 / 状态 / 删除 / + 增加一笔）

预估改动：后端 3 个文件 + 前端 2 个文件 + 测试；不涉及数据库迁移（退费库存已支持该来源类型）。
