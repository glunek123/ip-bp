## 行为

待归档阶段的列表主操作统一为「结案更新」，两种情况打开**同一张结案资料卡**：

| 案件状态                 | 卡片模式   | 字段                     |
| ------------------------ | ---------- | ------------------------ |
| 未登记                   | 登记       | 与首次登记相同，全部可填 |
| 已登记                   | 更正       | 同一套字段，全部可改     |
| 仅有结算权限、无结案动作 | 结算卡兜底 | 保持原有结算编辑         |

实现要点：

- `listActions` 在待归档优先取 `record-closure` / `correct-closure`，作为唯一主操作
- 有结案动作时不再并列 `settlement-update`，避免同名入口
- 抽屉标题统一用短标签「结案更新」
- 结算更新（付款记录/退费/实际回款）仍在案件详情的「更多操作」中，本次未并入结案卡
