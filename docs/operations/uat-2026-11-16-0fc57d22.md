## 自动清理

部署脚本新增第 8 步，位于重启与健康检查之后：

| 规则       | 值                                           |
| ---------- | -------------------------------------------- |
| 触发条件   | 仅当 `health=200`；否则打印 skip 并跳过      |
| 发布目录   | 保留最近 5 个，`current` 指向的目录永不删除  |
| 数据库备份 | 保留最近 10 份                               |
| 权限       | 以 `sudo -n` 执行（release 目录属主为 root） |

脚本片段：

```bash
echo "== 8. prune =="
if [ "$HEALTH" = "200" ]; then
  sudo -n bash -c '
    keep=5
    cur=$(readlink -f /srv/ip-bp-uat/current)
    cd /srv/ip-bp-uat/releases || exit 0
    ls -1t | tail -n +$((keep+1)) | while read -r d; do
      [ "/srv/ip-bp-uat/releases/$d" = "$cur" ] && continue
      rm -rf "$d" && echo "pruned release $d"
    done
    cd /var/backups/ip-bp-uat 2>/dev/null || exit 0
    ls -1dt case-* 2>/dev/null | tail -n +11 | while read -r b; do
      rm -rf "$b" && echo "pruned backup $b"
    done
  '
else
  echo "skip prune (health=$HEALTH)"
fi
```
