## 实现

**后端**（新增，复用既有 `fflate` 依赖）

| 文件                                   | 职责                                                                                                                                                         |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `case-execution-archive.controller.ts` | `POST /cases/execution-documents/archive`，body `{ caseIds: string[1..20] }`，返回 `application/zip`                                                         |
| `case-execution-archive.service.ts`    | 逐案 `CaseReadService.get`（自带 `case.read` 权限）→ 取 `executionSubmission.current`（退化到最新提交）→ `MaterialService.openVersion` 读流 → `zipSync` 打包 |

细节：

- 目录结构 `业务编号/原始文件名`，同名自动加 `(1)(2)`
- 文件名与路径做非法字符清理（`\ / : * ? " < > |`）
- 响应头带 `X-Archive-Case-Count`、`X-Archive-File-Count`、`X-Archive-Skipped`
- 每案跳过时记录业务编号，前端汇总提示

**前端**

| 位置               | 改动                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `api/cases.ts`     | `archiveExecutionDocuments(caseIds)`，上限 20 件，解析跳过列表与文件数                                            |
| `CaseListPage.vue` | 阶段组为 `EXECUTION_PREPARATION` 时显示「批量下载执行文书」，勾选 1–20 件可用；下载后提示结果；无文书时不产生空包 |
