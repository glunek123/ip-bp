# v6 测试环境版本交接

本轮交付范围为已确认的[v6需求](../superpowers/specs/2026-10-26-v6-operations-optimization.md)。版本、构建和实际验收结果以交付包根目录的`VERSION.json`及[验证记录](../spec/v0.1/VALIDATION.md)为准。本页不构成任何现有数据库迁移、历史重编号、真实账号增权或服务器部署授权。

## 主要变化

- 页面沿用“知产案管系统”；运营字段显示中文，接口及数据库业务编码保留。客户基本资料合并展示，移除开票入口，保留历史数据；详情、办理侧栏和结算区域使用紧凑分组。
- 导航区分本人案件与部门案件；“案件办理组”显示为“案件系列”。案件列表增加横向操作、来源和负责人布局，支持案件CSV预览／导入、选中导出与批量提前归档。
- 客户ID按全局创建顺序分配，线索与外录案件共享客户当天序号。首案保留线索号，多案从`-02`继续；三位不足时自然扩位。UUID及原证据关联保留，旧业务编号存入别名记录。
- 商品截图随商品行保存，也可在待推送及推送后的在办阶段补传；已归档只读。不猜配历史截图，也不改写已经引用的公证或案件证据。
- 企业账号创建权限与人员管理权限拆开；运营准入仍由后端检查当前部门、客户范围和证明材料权限。角色模板的“选择全部内部权限”不会自动保存或给账号增权。
- 提前归档保留原阶段、材料、费用和审计；归档不等于结清。已发起或已支付费用可先作废，支付情况待核实；支持按实际支付登记部分、多次退款，不用费用面额代替真实支付金额。

多模态识别不在本轮。本包不附仿真数据导入方案，测试环境仿真数据由用户指定的另一个任务准备。

## 部署前的编号切换准备

本版包含184项迁移，新增179至184分别涉及编号、企业账号创建权限、提前归档、商品截图、案件CSV／批量回执、费用作废／支付核实／退款事实。新增权限不会自动授给已有角色。

**只运行`migrate deploy`不足以启用新编号。** 179迁移把编号分配器保留为未初始化状态。已有库必须在取得该目标库的单独授权后，完成历史切换；空库也必须经过初始化。未初始化时，系统拒绝依赖新编号的创建，不回退临时编号。

1. 固定服务器目标、当前应用版本、迁移账本和本包版本；核对数据库及私有文件的备份和恢复办法。记录客户、线索、案件数量，以及软删除客户、普通来源案件和外录案件的来源一致性。确认本包既有迁移checksum与目标库一致。
2. 先在获准的隔离副本演练本包全部迁移与[编号切换草稿](../superpowers/plans/2026-10-26-v6-numbering-cutover.draft.sql)。该草稿不由Prisma自动执行；真实库执行前须针对目标数据量审查锁表时间、预检结果、备份、停写窗口和脚本SHA。
3. 停止所有应用写入及后台调度。在受保护的服务器环境配置下执行正式迁移。按单独批准的操作单执行编号切换事务；失败保留错误并回滚，不手动跳过来源、历史或唯一性校验。不得对既有环境运行reset或migrate dev。
4. 在保持停写时，独立比对UUID、原编号别名、新编号、客户与日计数器、首案及多案后缀、历史回执重放和关键财务／材料事实。通过后才启动本版写入。

切换完成后，不能把直接启动旧应用当作可用的写入回退方案：旧应用可能无法满足新的编号约束。异常先停写，按目标环境已批准的整体恢复或向前修复方案处理；不得删除新事实、别名或材料来强行兼容旧应用。

## 应用与权限配置

1. 核对包的SHA-256及`VERSION.json`。解压后`app/`为项目根目录；使用Node24.21.0、pnpm11.27.0及包内锁文件，在服务器平台执行`pnpm install --frozen-lockfile`，不复制开发机的`node_modules`。
2. 沿用服务器受保护的环境配置和独立私有文件目录，不复制开发机`.env`。同源HTTPS、反向代理、私有存储及备份规则见[UAT环境说明](uat-environment.md)。
3. 在获准迁移与编号切换完成后，前端提供`frontend/dist`，后端在`backend`目录使用受保护配置运行`dist/main.js`。如需重新构建，使用同一源码的`pnpm prepare:prisma`和`pnpm build:prepared`，不混用候选产物。
4. 真实账号增权由现有获准管理账号另行办理。“全权限运营”仍受当前部门及各动作允许范围限制；只允许本人办理的动作不会变成任意案件写入。不得重复运行首次账号引导来改造已有账号。
5. 部署后核对页面版本、登录及当前部门、新建客户和合作协议后补、线索商品截图、案件CSV无重复及人工确认路径、提前归档、费用作废与真实退款登记。另核无权限和跨部门拒绝；本机验收不能替代服务器上的这些检查。

本轮不连接云端，不部署服务器，不给真实账号增权。旧`f6ae58ad`部署包保持原样；本轮新版须以独立版本清单识别，不能仅凭文件名判断已验收。
