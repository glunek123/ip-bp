## 场景一：律师库建档（3 分钟）

1. 左侧「设置」→「律师库」。
2. 右上「新建律师」，填写：
   - 姓名：`测试律师-你名字缩写`（例如 `测试律师-xy`）
   - 律所：`测试律所`
   - 手机、执业证号、地区随意填，能过校验即可
3. 保存。

**预期**：列表出现该律师，状态列显示「未开通账号」，承办数列为 0。
**再验一次**：点该行「编辑」，改律所名保存，列表跟着变。

## 场景二：诉讼阶段补指派无账号律师（5 分钟）

用案件 `06120261118013`（待写诉状、未指派）。

1. 「部门案件」→ 搜索业务号 `06120261118013` → 打开详情。
2. 右上按钮显示「指派律师」，点击。
3. 在抽屉搜索框输入你刚建的律师名，列表出现该律师，标注「（未开通账号）」；选中后下方出现提示「该律师未开通系统账号：指派不受影响，交付与律师结算由运营线下跟进。」
4. 点「确认指派」。

**预期**：顶部承办律师显示该律师；案件阶段仍是「待写诉状」，没有前进。
**再验一次**：再点「变更承办律师」，确认可以换人。

## 场景三：无律师案件录律师结算并发起（5 分钟）

用案件 `00320261118744`（待归档、无律师、已补录结案 80000.00）。

1. 打开该案件 → 「费用管理」标签页。
2. 页面显示「案件结算」双栏：客户结算 / 律师结算。律师侧此时应显示「已发起 0 次」「律师结算金额 待定」。
3. 展开「编辑条件、发起结算与查看完整历史」。
4. 切到「律师结算」侧，填写：
   - 律师结算模式：固定费用
   - 基础费（元）：`100`
   - 分成比例：`30`
   - 律师结算金额（元）：`100`
5. 点「保存本案结算条件」。

**预期**：提示「本案结算条件已保存」；律师侧「结算条件」变成「固定费用 · 基础费 100.00 元 · 分成 30%」，律师结算金额 100.00 元。
> 注意：会看到「该案件未指派律师：条件可先录入，结算金额记为待归集」——这是提示，不拦截。

6. 点律师摘要卡的「发起结算」。

**预期**：律师侧「已发起 1 次」，按钮置灰并提示「律师侧已没有待发起金额」。
如果按钮置灰且提示「当前案件阶段不可发起结算」，说明选错了案件（必须是待归档）。

## 场景四：结算中心核对收付方（2 分钟）

1. 左侧「结算中心」→ 切到「律师结算」标签。
2. 找业务号 `00320261118744`：金额 100.00，**收付方显示「—」**（因为该案件确实没有律师）。
3. 对比找 `00920261118139`：收付方显示「曹月 / 浙江剑正律师事务所」（该案件有律师）。

**预期**：
- 案件有律师 → 收付方显示律师名与律所；
- 案件无律师 → 收付方显示「—」；
- 若「结算没挂律师、但案件已有律师」，会显示「律师名（待归集）」——当前 UAT 还没有这种组合，等补指派恢复后才会出现。

## 已知限制（遇到不是 bug）

| 现象 | 原因 |
| --- | --- |
| 待归档 / 已归档 案件补指派 | 2026-11-24 起已支持：这些阶段的案件版本被冻结，指派只写承办关系、不递增版本。执行中、待执行文书阶段仍可能因执行链缺失报「结案或归档记录不完整」，遇到请联系管理员。 |
| 无律师结算的收付方一直是「—」 | 结算本身没挂律师，案件也没律师。等指派后才会显示律师名。 |
| 结算「发起结算」置灰提示「律师侧已没有待发起金额」 | 该侧的额度已发完，不是权限问题。 |
| 律师库列表看不到某个律师 | 检查筛选条件；或该律师档案不属于当前部门。 |
