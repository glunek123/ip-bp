# 2026-11-23 下午：放宽承办律师补指派窗口（已部署 13672a99 / bc443bf4）

## 需求来源

方案 A（用户确认）：案件详情补指派入口上线后，只有「待写诉状／确认诉状」两阶段可见；待正式立案、待提交立案、待归档等大量无律师案件仍无入口，待归档案件也因此无法发起律师结算。

## 决定

**锁定的是已建立的承办关系，不是空缺本身**：

| 场景                     | 阶段窗口                   | 行为                                       |
| ------------------------ | -------------------------- | ------------------------------------------ |
| 当前无承办律师（补指派） | 全部阶段，含已归档         | 只递增案件版本，不推进阶段                 |
| 已有承办律师（变更）     | 待匹配／待写诉状／确认诉状 | 结束旧指派、建立新指派，阶段不变           |
| 待匹配阶段               | 仍走「匹配律师」表单       | 指派与结算约定一次落库，不在详情页另开入口 |

已归档案件同样放开：结算在 `WAITING_ARCHIVE` 与 `ARCHIVED` 都可登记，缺收付方时律师结算无法发起。
