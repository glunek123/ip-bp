## 三次尝试与失败原因

| 尝试                           | 结果 | 原因                                                                                                     |
| ------------------------------ | ---- | -------------------------------------------------------------------------------------------------------- |
| 一审（受理 + 开庭）            | 回退 | 测试用 `getComponent` 取到抽屉常驻实例，而非内联实例；改取内联后「发回重审」用例又因入口变化失败         |
| 一审（仅受理内联，开庭跳抽屉） | 回退 | 开庭面板依赖 `selected-command` 与抽屉开启状态，跳转后再次进入时草稿被清                                 |
| 判决 + 执行（三命令 tabs）     | 回退 | 抽屉 `v-if="openedCommands.has(...)"` 与内联 `v-if` 同时存在，同一面板出现两个实例，提交落在已卸载实例上 |

## 根因

面板在抽屉中常驻渲染（`v-if openedCommands` + `v-show selectedCommand`），内联再渲染一份 → 双实例。测试与运行时都无法确定"当前可见的是哪一个"。
